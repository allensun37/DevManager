# DevManager v0.5 Database Persistence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in SQLite backend, transactional migrations, storage-level query/pagination, and compatible HTTP pagination while preserving JSON as the default and retaining v0.4 rollback, ID, and API semantics.

**Architecture:** `ProjectManager` remains the business-state owner and commits a prebuilt candidate only after `ProjectRepository` succeeds. A new pure `query` component defines storage-neutral query semantics shared by JSON, in-memory operation, and SQLite; SQLite resource management stays in infrastructure, while `RepositoryFactory` selects the active backend during bootstrap.

**Tech Stack:** C++17, CMake 3.20+, SQLite 3.53.4 official amalgamation, nlohmann/json 3.12.0, cpp-httplib, spdlog 1.15.1, GoogleTest 1.17.0, OpenAPI 3.0.3, Ubuntu/GCC and Windows/MSVC GitHub Actions.

- [ ] **Step 3: Implement operation-specific candidate commits**

Replace `commitCandidate(ProjectStore)` with three private helpers:

```cpp
void ProjectManager::commitCreated(ProjectStore candidate, const Project& created) {
    if (repository_ != nullptr) {
        repository_->create(created, candidate.nextId);
    }
    projects_.swap(candidate.projects);
    nextId_ = candidate.nextId;
}

void ProjectManager::commitUpdated(ProjectStore candidate, const Project& updated) {
    if (repository_ != nullptr) {
        repository_->update(updated);
    }
    projects_.swap(candidate.projects);
    nextId_ = candidate.nextId;
}

void ProjectManager::commitRemoved(ProjectStore candidate, ProjectId removedId) {
    if (repository_ != nullptr) {
        repository_->remove(removedId);
    }
    projects_.swap(candidate.projects);
    nextId_ = candidate.nextId;
}
```

Build the final `Project` inside the candidate before calling the helper. No allocation or copy may occur after the Repository call; `vector::swap` and scalar assignment form the in-memory commit.

```cpp
void JsonProjectRepository::create(const Project& project,
                                   ProjectId nextIdAfterCreate) {
    ProjectStore candidate = loadStore();
    if (std::any_of(candidate.projects.begin(), candidate.projects.end(),
                    [id = project.id()](const Project& item) { return item.id() == id; })) {
        throw std::runtime_error("Project ID already exists in JSON store");
```

```cpp
public:
```
