# CLI Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the DevManager v0.1 loop menu on top of the existing application and JSON repository layers.

**Architecture:** `main` composes `JsonProjectRepository("data/projects.json")`, `ProjectManager`, and `MenuController`. `MenuController` accepts input/output streams and only performs terminal interaction; all project rules stay in `ProjectManager`, while JSON I/O remains in the repository.

**Tech Stack:** C++17, CMake, CTest, nlohmann/json, standard streams.
